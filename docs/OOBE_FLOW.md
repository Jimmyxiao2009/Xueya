# 首次学习引导

Cloud 用户先注册／登录。读取账号路线成功且为空时，直接进入主题页；已有路线的账号进入学习首页。读取失败保留重试和切换账号入口，不把失败当作空账号。

三页共用 `CreateRouteScreen`，用于首次进入、后续新建路线及桌面原生本地模式：

1. 你想学什么：单输入框与六个可填写的候选，顶部 3 px 进度条，无步骤编号。
2. 接触程度、学习深度：两个原生三档滑块，也可点击刻度；支持键盘，返回保留选择。右下角跳过采用从未接触、能够应用。
3. 添加资料：文件、URL、关键词网页搜索、AI 寻找资料。资料显示读取中／已读取／失败；只提交成功读取的唯一 source ID。无需第四页确认。

桌面采用居中宽内容区，资料页双栏；700 px 以下单栏。样式使用现有主题变量，宽度规则仅覆盖引导；首页样式不受影响。

## 检索

`search_web` 新增可选 `ai`，默认 false，兼容现有调用。AI 模式由已配置聊天模型生成检索词，搜索真实网页，再从所有候选中筛选最多三条适合的资源。排名只允许返回实际候选索引；网页标题和摘要作为不可信内容处理。排名失败时返回实际检索结果；整个调用失败时显示错误，用户仍可自行添加资料。

已有 Brave 密钥优先。没有 Brave 密钥且未显式禁用搜索时，只复用启用的 `api.stepfun.com` 服务密钥，调用 `https://api.stepfun.com/v1/search`。密钥仅留在后端。网页读取沿用 IngestionService 的 URL 检查和导入流程。搜索质量与可访问性取决于检索服务及来源网站，用户可移除自动选入的资料。

接口参考：[Step 搜索 API](https://platform.stepfun.com/docs/zh/api-reference/search/search)。

开发模型已改为 `step-3.7-flash`，配置保存在忽略提交的 `.env.local`，延续大纲 Agent + 每节点内容 Agent 结构。
