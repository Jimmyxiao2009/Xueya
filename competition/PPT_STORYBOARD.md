## 全局设定

| 项 | 决定 | 理由 |
| --- | --- | --- |
| 时长假设 | 5–8 分钟路演 + 现场 Demo | 14 页正片，平均每页 20–30 秒 |
| 画幅 | 16:9（13.333" × 7.5"） | 赛场投影标准 |
| 视觉基调 | **Lighthouse 暗雾**为 PPT 主基调：底 `#0d1114`、面板 `#131a1f`、正文 `#e8eae7`、次要 `#a9b2b0`、灯光 `#e6c084`、暖橙 `#d9a866`、掌握绿 `#b9d0a8`、复习紫 `#8d97a3`、雾 `rgba(148,168,178,.05–.10)` | 与产品签名视觉一致；暗场在投影上更聚焦；截图多为暗色，嵌入不突兀 |
| 字体 | 标题/正文：微软雅黑（赛场机器保底）；大数字：Georgia | 产品 display 字体为衬线（Songti 系），但赛场 Windows 机不一定有，用字重/字号/颜色做层级，不冒险 |
| 每页文字上限 | 标题 ≤ 12 字；正文每点 ≤ 2 行；整页 ≤ 60 字（不含图注） | 讲清楚 > 堆信息 |
| 叙事隐喻 | 雾 → 灯塔 → 航路 → 点亮。只用在封面、过渡、收尾三处，中间页克制 | 文艺不过头 |
| 诚红线 | ① 离线/Mock 输出必须标注；② Android 只说"构建链路就绪、真机验证中"；③ 向量引擎基准用诚实口径（见 P12）；④ MasteryEvidence/ConceptState 是领域类型（映射现有表），不说"独立证据链数据库" | 可信比吹牛重要 |

## P4 · 学涯是什么

- **页码**：4
- **页面标题**：一个会陪你走完的学习 Agent
- **唯一记忆点**：**导入资料 → 生成路线 → Agent 对话式教学 → 路线随你作答而改变。**
- **页面内容**：
  - 一句话定位（大字）：把你手上的资料，变成一条会随你作答而改变的学习路线。
  - 学习闭环一行横排（8 个环节，小字+节点）：来源 → 综合 → 路线 → 学习 → 提问 → 诊断 → 调整 → 复习（首尾用虚线回连成环）
  - 一排"它不是什么"（灰色小字，划线感）：不是题库 · 不是出题器 · 不是摘要工具 · 不是套壳聊天 · 不是固定课程播放器
- **视觉布局**：中央闭环为主视觉；下方"不是什么"一整排弱化处理。
- **需要截图**：无
- **需要图表**：八环节闭环图（重绘，节点样式与产品路线图同款圆点）
- **演讲者讲什么**："学涯做的事一句话：把你的资料变成一条学习路线，然后由一个 Agent 用对话陪你走完。这八个环节全部发生在你自己的机器上。注意'调整'这一环——你答错，路线本身会长出一个复习节点。这不是课程列表，路线是活的。它不是什么？不是题库、不是摘要器、不是套壳——这些形态都不会'调整'。"
- **过渡**："光说不够。直接看它和真实学生的一次对话——" → P5

## P5 · 核心 Demo：一段真实的教学对话（全片中心页）

- **页码**：5
- **页面标题**：它不说"错误"，它给你一个反例
- **唯一记忆点**：**Agent 主动开口 → 学生答错 → 反例追问 → 学生自己发现矛盾 → 路线自动插入加练。**
- **页面内容**（对话流，自上而下 6 个气泡，左侧 Agent / 右侧学生；每个 Agent 气泡右上角标注它使用的教学动作标签）：
  1. `Agent · Ask（开场白，学生还没说话）`："先不急着记定义。关于'无穷远点'，我想先请你判断：把'方向'本身变成一个点，它和普通的点有什么区别？"（此为离线 fixture 路线中真实记录的开场白模式，见证据清单）
  2. `学生`："无穷远点就是非常非常远的点。"
  3. `Agent · Counterexample`："如果它只是'很远'，那沿着一条直线走足够远应该能到达。可两条平行线永远保持同样距离——它们会在那里相交吗？"（不说"错误"）
  4. `学生`："……等等，按我的说法平行线也能相交，这矛盾了。"
  5. `Agent · Transition`："对，矛盾就在这里。平行线确实相交——交在无穷远点。这正是射影平面要引入它的原因。"
  6. 系统条（紫色）：⚡ 检测到误解 → 已在你的路线插入「加练 · 无穷远点」（真实 adaptation 行为）
  - 页脚一行小字：教学动作来自 `AgentActionKind` 13 种动作枚举；加练插入由 `AdaptationService` 执行并落库，重启后仍在。
- **视觉布局**：整页模拟产品对话界面（暗底、Agent 气泡深色面板、学生气泡暖色描边）；动作标签用小药丸（Probe/Ask 用灯光色，Counterexample 用橙色，系统条用复习紫）；右侧边缘放一条迷你路线图，显示"加练"节点被点亮插入的瞬间。
- **需要截图**：`store/screenshots/03-tutor.png`（真实对话界面，裁剪后放右侧或作为底衬）；对话气泡为**重绘**（用真实开场白 + 按真实提示词行为演绎的对话，页脚注明"演绎自真实提示词与日志，现场演示为实时生成"）
- **需要图表**：迷你路线"插入加练节点"前后对比（可用 P8 截图局部，或重绘示意）
- **演讲者讲什么**："这是学涯最重要的一页。注意三件事：第一，先说话的是 Agent，不是学生——点开一节课，它用一个诊断问题开场。第二，学生答错了，它全程没说'错误'两个字，它给了一个反例，让学生自己撞上矛盾。第三，也是最难得的——这次误解不只停留在对话里，路线图上真的长出了一个'加练'节点，重启应用它还在。对话改变了课程结构。这就是我们说的：Conversation 是课堂，路线是活的。"
- **过渡**："这段对话背后不是一个提示词运气，是一整套机制——" → P6

## P6 · 学习 Agent 如何工作

- **页码**：6
- **页面标题**：每一轮，它都在做教学决策
- **唯一记忆点**：**每轮输出 = 一个教学动作 + 一次理解诊断，诊断会真的改变路线。**
- **页面内容**（一张主流程图，无代码）：

```text
当前知识点 + 对话历史 + 掌握度/置信度 + 检索到的资料证据 [C1..Cn]
                        ↓
                 Teaching Agent
                        ↓
        下一轮教学动作（13 选 1）
  Ask · Probe · Hint · Example · Counterexample · Explain
  Challenge · Reflect · Summarize · Transition · Exercise · Quiz · CompleteConcept
                        ↓
        诊断 Diagnosis（误解类型 × 置信度 × 严重度）
                        ↓
   置信度 < 0.55 不行动 ｜ 误解/反复失败 → 插入复习 ｜ 低置信 → 安排复习
```

  - 三个设计原则小字：先问后讲（ask before tell）· 先提示后给答案 · 先探查后纠正
  - 诚实标注：`MasteryEvidence` 等为领域模型类型，持久化在既有学习记录表中（非独立新表）。
- **视觉布局**：上图下文；流程图纵向居中，输入四项做成四张小卡片汇入 Agent 圆环；动作列表用 13 个小药丸网格；底部诊断决策用三分支。
- **需要截图**：无
- **需要图表**：Teaching Agent 决策流程图（重绘，全片最重要的一张图解）
- **演讲者讲什么**："每一轮对话，Agent 拿到四样东西：当前知识点、历史对话、这个学生的掌握度和置信度、以及从他自己资料里检索到的证据。它输出的不是一段话，而是一个教学动作——提问、提示、举例、反例……共十三种。同时它给出诊断：这是误解还是部分理解？置信度够不够？低置信度的诊断不会扰动路线；确认是误解，才插入复习。教学决策是有阈值、可审计的。"
- **过渡**："Agent 决定'怎么教'，但学生首先要知道'去哪里'——" → P7

## P7 · 学习路线：要去哪里 vs 怎么走过去

- **页码**：7
- **页面标题**：路线负责方向，Agent 负责陪走
- **唯一记忆点**：**学生面对的不是无限聊天框，而是一条有目标、会因他而改变的路径。**
- **页面内容**：
  - 左半：真实路线图截图（射影几何，含"为你插入 · 复习"紫色节点）
  - 右半三行：
    - Roadmap 告诉你"要去哪里"：章节、节点、先后依赖、预计时长
    - Agent 负责"怎么陪你走过去"：对话、追问、检查、加练
    - 答错 → 路线插入「加练」节点并在首页说明原因；掌握 → 点亮下一站（灯塔变亮）
- **视觉布局**：左图右文；截图外加细边框（模拟设备）；右侧"加练节点"用一个紫色箭头从文字指向截图中的紫色节点位置。
- **需要截图**：`audit-results/theme-integration/home-buoy-light.png`（浅色 Buoy 路线，含"为你插入·复习 对偶原理"）或 `audit-results/new-user-live/completed-route.png`（暗色，含"加练·概率基础与分数表示"）——两张都真实含 adaptation 节点
- **需要图表**：无额外（截图本身即证据）
- **演讲者讲什么**："纯聊天框的问题是：学生不知道自己在哪、要去哪。学涯把学习目标和路径显式化——这条路线就是'地图'。而当你答错，地图上真的会长出新节点：这个紫色的'为你插入·复习'就是 Agent 插进来的，并在首页告诉你为什么。方向感和主动性，各司其职。"
- **过渡**："那条路线和对话里的证据，来自哪里？来自学生自己的资料——" → P8

## P8 · 你的资料，成为教学的上下文

- **页码**：8
- **页面标题**：不是 RAG 聊天，是"有据可依的教学"
- **唯一记忆点**：**导入的资料变成可引用的证据；Agent 每句话标明出处，答不上来会明说。**
- **页面内容**：
  - 左：导入 → 解析 → 分块 → 混合检索（FTS5 关键词 + 向量，按路线隔离）→ 进入教学上下文
  - 右：三条 grounding 诚实标注（这是和普通 RAG 聊天的分界）：
    - `source_grounded`：回答来自你的资料，附 [C1] 可展开原文
    - `model_knowledge`：来自模型自身知识，明说
    - `insufficient_source`：你的资料里没有，明说"没有"，不硬编
  - 底部小字：引用标签由后端映射回真实资料片段，模型编造的标签会被丢弃；资料内容以"不可信内容"边界注入，防提示注入。
- **视觉布局**：左侧纵向管线图；右侧三张 grounding 状态卡（绿/灯光/灰）；底部一行安全说明。
- **需要截图**：`audit-results/oobe-three-pages/desktop-materials.png`（导入页：文件/URL/AI 帮找）；若能补截"依据 · 展开引用"对话截图更佳（见资产清单 S-08）
- **需要图表**：导入→检索→教学 管线图（重绘）
- **演讲者讲什么**："学涯不是把 PDF 丢给模型聊天。资料经过解析、分块、混合检索，成为 Agent 的教学证据，而且按路线隔离——这条路线不会引用那条路线的资料。最关键的三态标注：这句话来自你的资料、来自模型、还是资料里根本没有——三种情况三种标注，评委可以在对话里点开'依据'直接看到原文片段。诚实，是可验证的。"
- **过渡**："这一切跑在哪里？——大部分，跑在你自己的机器上。" → P9

## P9 · 技术架构（仅此一页）

- **页码**：9
- **页面标题**：本地为核心，云端为增强
- **唯一记忆点**：**不登录、不联网，也能完整学习；云是增强，不是依赖。**
- **页面内容**（一张两层架构图，克制信息量）：
  - **Local Core（Rust · Tauri）**：学习会话 / 课程与路线 / 掌握度与适应 / 混合检索与向量索引 / SQLite 本地库
  - **Cloud（可选）**：账号与设备 / 额度 / AI 网关 / 增量同步 / 对象存储（MinIO/S3）
  - 中间连接：登录后同步元数据与资料；AI 三模式 `离线 · BYOK · Cloud`，云故障自动降级且明确标注，学习不中断
  - 角标一句：本地学习路径无需账号即可使用。
- **视觉布局**：左右两个圆角面板，Local 占 60% 且用暖光描边（视觉重心在本地），Cloud 40% 用冷色细线；中间一条双向箭头，箭头下方小字"可断开"。
- **需要截图**：无
- **需要图表**：两层架构图（重绘）
- **演讲者讲什么**："架构只有一页，因为原则只有一条：本地优先。学习、数据、路线、检索全部在本机 Rust 核心里，登录和联网都是可选项。云端提供账号、同步和 AI 网关——它是同一个 Provider 接口的另一种实现，不是另一套系统。云挂了，学习继续，界面会诚实告诉你现在是离线。这一点我们等下现场断网演示。"
- **过渡**："同一个核心，跑到不同的设备和主题上——" → P10
