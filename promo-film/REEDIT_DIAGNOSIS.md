# REEDIT_DIAGNOSIS — final_candidate.mp4 叙事诊断

## 核心问题：镜头质量 ≠ 叙事连续性

逐段重看 v1，每个场景单独成立，但场景之间是"切换"不是"转化"：

| v1 段落 | 问题 |
|---|---|
| S1 LOST 雾中信号 | 成立。但信号点出现后，没有"它在找什么"。 |
| S2 ARCHIVE 档案蒙太奇 | **最严重**。月面图、潮汐表、鸟翼、代码同时出现——观众无法知道它们与"一个问题"的关系。它们只是"很酷的知识素材"，属于 B/C 类镜头抢走了叙事。 |
| S3 MAP 星图连线 | 档案卡"缩小变成节点"方向正确，但节点标签（交比/齐次坐标…）与前面档案内容无提取关系——观众看到的是"卡片消失、图谱出现"，不是"文字从纸里被读出来"。中间断了一拍。 |
| S4 ORBIT 进入产品 | zoom 进产品的思路对，但雾掩盖了匹配关系：观众没有意识到"星图节点 = 产品路线图节点"。随后 roadmap→lesson→conversation 是三个并列页面展示，像功能导览。 |
| S5 THINK 对话 | 内容最好的一段（追问弧线真实），但绿圈扫描是孤立的强调动作，与开头的信号点没有被识别为"同一个东西"。 |
| S6 WORLD 解体+航标 | UI 解体方向正确，但学科名扫过（PHYSICS/HISTORY…）是"新的抽象场景"而不是"当前学习扩展到更大世界"——mastery 节点与学科之间缺因果。 |
| S7 BRAND | 轨道成形好看，但轨道来自"无"——绿点凭空开始画圆，与刚才的路线无关。 |

## 三个结构性结论

1. **没有贯穿的问题**。v1 讲的是"知识很多→变成路线→产品好"，观众记住的是氛围，不是故事。
2. **SIGNAL GREEN 是装饰不是主角**。它在 S1 是信号点、S2 是扫描线、S3 是节点、S5 是圈、S6 是光束、S7 是轨道——形态都对，但每一次形态转换都没有"亲眼看到它变形"，等于六个不同的绿色元素。
3. **字幕在替画面打工**。"Turn information into a journey" 出现时观众还没看到 journey；"Any subject can become a journey" 之前没有建立 subject 与 journey 的关系。

## 保留清单（对叙事有用的资产）

- 雾/暗氛围、颗粒、纸张质感 —— 世界底层，保留。
- 星图连线段的视觉（虚线路径+节点标签）—— 用于 ROUTE。
- map→UI 的 zoom 接缝 —— 改造为 node→ring→UI 的匹配转化。
- 真实 UI 截图与追问对话内容 —— 用于 LEARNING，但镜头必须每次只聚焦一个元素。
- 「保持不变」圈词 —— 保留，但改为绿点亲自完成扫描。
- mastery 点亮 —— 保留，作为 UNDERSTANDING 的产品内结果。
- 轨道收尾 —— 保留，但轨道必须由路线弯曲而成。
- 档案标本（月面/潮汐/鸟翼等）—— 降级为 EXPAND 段的"下一次旅程"质感层，不再开场抢戏。
