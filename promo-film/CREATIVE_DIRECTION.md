# 学涯 ORBIT — 宣传片创意方向

**版本** v1 · 2026-09-20 · 基于仓库实拍素材
**产品**: 学涯 / ORBIT（Verruckt 为内部代号，全片不出现）

---

## 1. 产品理解（从代码与实拍中提取的事实）

学涯不是"问答 AI"，它的产品骨架是：

- **路线即主页**。Home 不是 dashboard，是一条手绘虚线路径 + 漂浮节点卡（`RoadmapScreen` 注释原文："a hand-drawn dotted path with floating nodes, not a dashboard or a list"）。节点会"为你插入 · 复习"——答错不阻塞流程，而是改变路线图本身。
- **灯塔即 AI**。产品里灯塔资产被注释为 "the brand anchor and the visual identity of the AI"；暗色灯塔主题就是"暗雾 + 暖灯光"（`--bg:#0d1114`, `--light:#efd7a4`）。**暗 = 未探索，亮 = 已理解** 不是宣传片的发明，是产品自己的语义（节点状态 `unlit / current / lit`，文案"以理解，点亮未知"）。
- **对话即学习**。LearningScreen 的注释："学涯 asks, the learner answers, and the plan above lights up one step at a time; a wrong answer never blocks the flow, it changes the roadmap behind it instead." 教学动作是 Explain / Ask / Probe / Hint / Example / Challenge / Reflect / Summarize，Quiz 只是可选的"阶段检查"。
- **纸张即材质**。亮色主题是暖纸（`#f8f7f4`）+ 墨字 + 陶土红 accent；衬线展示字体（Iowan Old Style / Songti 方向）承担标题。
- **已有的品牌文案语气**："让好奇心，有路可循。""每一点好奇，都有下一步。""路线会随你的理解，继续生长。""有疑问，随时打断我…" —— 安静、克制、编辑化，不是 SaaS 腔。

**结论**：宣传片不需要"发明"一个世界再套到产品上。产品内部已经住着这个世界（雾、灯、路、档案）。影片的工作是把它放大成电影语言。

## 2. 品牌世界：THE ATLAS OF LEARNING

知识航海档案。未知是暗的海，学习是测绘与点灯，AI 是导航者，学习者是旅行者。

叙事骨架（也是色彩语法）：

```
UNKNOWN → SIGNAL → MAP → ROUTE → JOURNEY → UNDERSTANDING
  暗       绿点      图     线      真实UI      亮
```

## 3. 视觉语言

### 3.1 两种真实，一种物理

影片里存在两层画面，它们必须服从同一套物理（雾、光、扫描、连线、缩放）：

| 层 | 内容 | 材质 |
|---|---|---|
| **图谱层**（合成） | 等高线、星图、坐标、公式、标本图鉴、纸卡 | 石墨线稿 + 纸纹 + 雾 |
| **产品层**（实拍） | roadmap / lesson / conversation / generating 真实 UI 截图 | 暖纸与暗雾，保持产品原色 |

### 3.2 色彩

- 纸象牙 `#f6f2ea`、暖白 `#fffefa`、石墨黑 `#17191c`、炭黑 `#23262b`
- 雾灰 `#9aa5a8`、灰绿 sage `#8fa08c`、极淡天蓝 `#bccdd6`
- **SIGNAL GREEN `#35d0a5`**（只在图谱层与仪器层使用：扫描线、坐标、节点 ping、进度、片尾轨道线）
- 产品 UI 保留自身暖琥珀灯光 `#e6c084` —— 绿色是"测绘仪器"的颜色，琥珀是"产品里的灯"。两者分工不冲突：绿 = 寻找，暖 = 抵达。

> 这条分工是全片最重要的色彩决定：遮住 Logo 后，观众记住的是"雾 + 绿色信号 + 纸上地图"；进入产品后，绿色信号变成琥珀灯光——同一个隐喻的两种材质。

### 3.3 字体

- 拉丁展示：**Palatino Linotype**（衬线、档案感，与产品 `--font-display` 同源）
- 中文展示：**宋体 SimSun**（档案印刷感，用于大字标题与旁白）
- 仪器/坐标/标签：**Cascadia Mono / Consolas**（等宽，全部小号、字距拉开、大写）
- 全部为系统字体，无授权风险（见 README_PROMO.md）

### 3.4 质感规则

- 图纸元素用**细线稿**（1px 级），不用填充色块。
- 纸纹 = 程序生成颗粒 + 极淡纤维线，不做破旧做旧。
- 允许 2–10 帧的"好奇心闪帧"：月面图、潮汐表、鸟类标本线稿、几何证明、电路板走线——全部以同一线稿风格程序绘制，**不解释，只出现**。
- 禁止：蓝紫渐变、发光大脑、粒子球、HUD 科幻框、聊天气泡 montage、stock 素材。

## 4. Motion grammar（全片只允许这几种转场/运动）

1. **FOG** — 雾的聚散完成淡入淡出与遮罩。
2. **LIGHT** — 一道扫光揭示内容（扫描 = 测绘仪器）。
3. **MAP ZOOM** — 图谱 ↔ 文档 ↔ UI 之间的连续缩放，是"进入产品"的唯一方式。
4. **CIRCULAR SCAN** — 圆形扫描/镜片/轨道，用于识别与聚焦。
5. **CONNECTION** — 节点与线连接成路径。
6. **DECONSTRUCTION** — UI 元素解体为纸、节点、线、坐标（产品 → 世界的回程）。
7. **OCCLUSION** — 前景纸卡/图层擦过完成硬切。

禁止 crossfade 滥用；允许 1 秒以内的 hard cut、静帧、大量留白、突然静音。

## 5. 剪辑人格

- 前 5 秒：极慢，只有雾和一个信号。
- 5–13 秒：突然加速，档案蒙太奇，cut 密度最高（0.4–0.9s/shot）。
- 13–21 秒：减速，连线成图——让观众"看到思考发生"。
- 21–32 秒：进入真实产品，镜头变成克制的推轨与视差。
- 32–42 秒：全片最安静。"Not answers. / Understanding." 前后留 1 秒空白。
- 42–52 秒：UI 解体回到图谱世界，学科名扫过，音乐到顶。
- 52–60 秒：全部收掉，一声 ping，绿点画一条轨道，出字。

## 6. 声音语言

程序合成（`audio/score.mjs`，无采样版权风险）：

- 底层：海风（棕噪声 + 慢低通呼吸）+ 极低频 pulse
- 信号：sonar ping（880Hz 指数衰减 + 三次回声）——全片的"逗号"
- 档案段：纸张/铅笔质感（高通噪声短促包络簇）
- 扫描：带通噪声扫频 + 上升正弦
- 中段：失谐三角波 pad（D–A–E 开阔和声）+ 机械 click 节拍
- "Not answers." → 全部抽掉，只剩房间底噪
- 片尾：ping → 轨道绘制时的细高频"划线声" → 静默 0.5s → 结束

## 9. 真实性边界

- 所有标"实拍"的镜头来自 `shots/` 下 13 张 4K 截图（preview fixtures + 运行时 mock IPC，未改产品一行代码）。
- 对话文案是剧本化 mock（tutor 追问弧线），展示的是产品真实的交互结构与排版，不虚构产品没有的能力。
- 生成中（generating）画面使用真实界面 + mock 进度。
- 无法在浏览器里还原的能力（如云同步）全片不出现。

## 10. 自检三问（每个段落交付前过一遍）

1. 遮住 Logo，这还是 ORBIT 吗？—— 靠"雾+信号绿+图纸线稿+同一套转场物理"保证。
2. 这个镜头会属于任意一家 AI 创业公司吗？—— 一旦出现通用 chat 气泡、发光大脑、蓝紫渐变，重剪。
3. 我在展示产品，还是在解释产品背后的想法？—— S4/S5 展示产品（真实 UI），S1–S3/S6–S7 解释想法（图谱世界），S4 的 map zoom 是两者的接缝。
