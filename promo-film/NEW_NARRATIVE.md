# NEW_NARRATIVE — 学涯 ORBIT · v2 因果链

## 贯穿全片的唯一问题

**「平行的铁轨，为什么在远方相交？」**

选择理由：
- 一眼可视（两条线收拢到一点，无需文字就能看懂"这里有个问题"）。
- 与产品真实 demo 内容完全同构：产品 fixture 的路线就是「射影几何」（射影平面基础 → 齐次坐标 → 交比与调和分割 → 对偶原理 → 二次曲线 → 配极变换），已截获的真实对话正是用"铁轨投影到视网膜"讲交比。
- 不虚构产品能力：路线节点名、对话内容、当前节点（交比与调和分割）全部来自真实 capture。

## 因果链（每场由上一场变形而来）

```
QUESTION        雾中，一副透视线稿自己画出：铁轨收拢到消失点。
                绿点在消失点亮起 —— 问题就是从这里发出的。
   ↓ 绿点发出一次 pulse，脉冲环扫过黑暗
TOO MUCH        脉冲扫过处，六份与【这一个问题】相关的资料显影：
                透视习作 / 铁轨图版 / 交比公式页 / 几何证明 / 视平线图解 / 教科书页。
                信息很多，没有顺序。（p≈overwhelming）
   ↓ 扫描线收回成绿点，绿点停在第一份资料上
STRUCTURE       绿点逐份"阅读"：圆扫描圈出关键词 → 关键词发绿 →
                从纸面脱离 → 飞离、缩小 → 成为绿色节点。
                六个节点正是产品路线的六个概念。纸堆随之暗淡。
   ↓ 绿点回到第一个节点，开始移动
ROUTE           绿点行经节点 A→B→C…，虚线在它身后连成学习路线。
                节点依次点亮。（此时才出现小字：Turn information into a journey.）
   ↓ 绿点停在第三节点「交比」，镜头随它推近
ENTER PRODUCT   绿点扩张成绿色圆环 → 环内起雾 → 雾散时发现：
                这个圆环就是真实产品路线图里"当前节点"的高亮环。
                镜头拉开：刚才的星图就是产品的路线图。
   ↓ 镜头推进当前节点卡片，纸面擦过
LEARNING        进入该节点的真实对话页。镜头沿对话向下行进（=对话在推进）：
                AI 提问 → 学习者回答「长度保持不变？」→
                绿点化作圆圈，圈出 AI 追问中的「保持不变」→
                学习者再答「交比」→ 绿点化作下划线 → AI 确认。
   ↓ 绿点从对话中升起，画面转暗
UNDERSTANDING   对应知识节点由暗转亮：MASTERY +0.12，虚线连回路线。
                声音几乎全部消失。黑场。
                Not answers.（停）Understanding. —— 观众已先看到过程。
   ↓ 从这个被点亮的节点，镜头持续拉远
EXPAND          节点回到地图；路线越过最后一个节点继续向雾里生长。
                周围浮出更多知识世界：PHYSICS / HISTORY / BIOLOGY / CODE /
                PHILOSOPHY / MUSIC —— 每一个都带一条自己的路线路。
                月面/潮汐/鸟翼等标本此时作为"下一次旅程"的质感幽灵出现。
   ↓ 其他一切淡去，只剩绿点与它脚下的路线
ORBIT           路线向上弯曲，绿点沿它疾行——路线弯曲成一个圆环。
                轨迹闭合：你走过的路，就是轨道。
                学涯 / ORBIT / Find your way through knowledge. / 一声 PING。
```

## 静音自测脚本（TEST A/B 的判卷标准）

关闭声音与全部 slogan 后，观众应能读出：
铁轨收拢（有问题）→ 一堆相关资料（信息过载）→ 词从纸里飞出来变成点（结构化）→ 点连成线（路线）→ 线进入真实产品（这是同一个东西）→ 一问一答一追问（引导不是灌输）→ 点亮（理解了）→ 拉远看到更多世界（可迁移）→ 线弯成轨道（品牌）。
