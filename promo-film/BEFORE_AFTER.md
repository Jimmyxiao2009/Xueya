# BEFORE_AFTER — v1 (final_candidate) → v2 (final_candidate_v2)

## 一句话

v1 是"一组漂亮的镜头 + 转场"；v2 是"一个问题长成一条轨道"。
v2 里每个场景由上一场的元素**变形**而来，SIGNAL GREEN 从第一帧到 Logo 从未离开画面。

## 结构性改动

| | v1 | v2 |
|---|---|---|
| 贯穿问题 | 无（泛知识氛围） | **「平行的铁轨，为什么在远方相交？」**（与产品真实路线"射影几何"同构） |
| 档案素材 | 月面/潮汐/鸟翼/代码随机并置 | 六份资料全部回答同一个问题；v1 的标本降级为 EXPAND 段的质感幽灵 |
| 纸→图 | 卡片缩小消失，图谱另行出现 | **关键词从纸面被扫描、提取、飞向节点**——连续变形，无 cut |
| 进入产品 | 雾中 zoom（匹配关系被雾遮盖） | 绿点扩张成环 → 环收拢为真实 UI 的"当前节点"高亮框（形状+位置匹配） |
| 对话段 | 五个教学标签的并列展示 | 沿对话向下行进的一次完整追问弧线；绿点化身为圈词圆环、下划线 |
| 理解 | 孤立黑场文案 | 先看到节点点亮（MASTERY +0.12）→ 静音 → 文案只是命名 |
| 结尾轨道 | 绿点凭空画圆 | **路线本身弯曲回环成轨道**；琥珀光点在路线与轨道的接合处 |
| 时长 | 60s | 54s |

## 逐镜处置

### 保留（含改造保留）
- 雾 / 颗粒 / 暗海图底 —— 世界底层材质，沿用。
- 真实 UI 截图 `02-roadmap-dark-lighthouse` / `05-learning-conversation-light` —— 仍是 S5/S6 主体，但镜头改为"一次只聚焦一个元素"。
- 「保持不变」圈词 —— 保留，改为绿点亲自拉成圆环（变形可见）。
- MASTERY +0.12 点亮 —— 保留，成为 UNDERSTANDING 的产品内结果。
- 轨道 + 学涯/ORBIT 落版 —— 保留构图，轨道改为由路线弯曲而成。
- 琥珀作为"灯/抵达"色 —— 保留其语义，只出现在路线已点亮节点、产品 UI、轨道接合点三处。

### 删除
- S2 的随机档案蒙太奇（月面/潮汐/鸟翼/代码/电路）—— 与单一问题无关，抢叙事。
- 五教学动作标签列（EXPLAIN/ASK/HINT/EXAMPLE/CHALLENGE）—— 是功能罗列，不是叙事。
- S6 的"航标光束扫学科名"抽象场景 —— 改为从 mastery 节点连续拉远扩展，学科名以"各自的路线"呈现。
- GENERATING/CREATE 界面镜头 —— 不服务"一次学习"的主线。

### 重排
- 档案标本（月面/潮汐/鸟翼）→ 移到 EXPAND 段，作为"其他知识世界"的低透明度质感层。
- 对话微距 → 从并列展示改为纵向行进的连续镜头（镜头下行 = 对话推进）。

### 重做
- S1 开场：抽象雾+信号 → 透视线稿自己画出来，绿点诞生在消失点。
- S3：新增"纸→词→节点"的提取动画（v1 缺这一拍）。
- 全部转场：改为变形（pulse/scan/lift/travel/ring-morph/zoom-out/curl），无一个通用转场插件。

## 两个测试的结果

- **TEST A（静音）**：contact sheet + 分段静帧确认故事节奏成立；声音只做情绪，不做解释。
- **TEST B（无营销标语）**：`?noText=1` 渲染版（`final/narrative_animatic_notext.mp4`）隐去开场问题、路线/扩展标语与片尾 tagline 后（仍保留产品原文、理解文案及品牌），"问题→资料→结构→路线→产品→引导→理解→扩展→轨道"九拍仍可辨认。

## 仍有取舍

- 对话文案仍是剧本化 mock（结构真实）；v2 镜头下的"教学"由镜头运动与绿色强调承担，不依赖读完文字。
- S5 的环→框匹配用雾覆盖了一帧尺度差，仔细看环的圆心与卡片中心有轻微偏移——v2.1 可再做亚像素配准。
